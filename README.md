# Fiteatsy Mobile

Fiteatsy is a healthcare platform centered on structured recovery journeys, consultant-guided nutrition care, report intelligence, and longitudinal client health data.

This repository currently contains:

- The React Native mobile application in [`src/`](/Users/l.paunikar/Desktop/fiteatsy-mobile/src)
- The Node backend foundation in [`backend/`](/Users/l.paunikar/Desktop/fiteatsy-mobile/backend)
- The official platform documentation in [`docs/`](/Users/l.paunikar/Desktop/fiteatsy-mobile/docs)
