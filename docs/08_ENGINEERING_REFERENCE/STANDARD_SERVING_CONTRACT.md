# Standard Serving Contract

A serving is food-bound and versioned. It records label, quantity/unit, exact grams or millilitres, conversion basis/source, preparation state, default state, permitted multiplier set, and active state. Every generator-eligible v15 seed has an exact gram conversion. Invalid, stale, inactive, or out-of-range multipliers fail closed. Household vessel mass is food-specific; a common capacity never implies a universal mass.
