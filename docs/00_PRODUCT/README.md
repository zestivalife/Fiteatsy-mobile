# Fiteatsy — 00 Product

**Document Group:** Product Foundation  
**Product:** Fiteatsy  
**Status:** Product Baseline

## Purpose

This folder defines what Fiteatsy is, the outcomes it is designed to support, its major product capabilities, and the boundaries that implementation must preserve.

Fiteatsy is a personal health, fitness, condition-management and recovery-support platform. It combines user-authorised health and wearable data, longitudinal medical-report and biomarker history, medication reminders, progress intelligence, and professional monitoring through the Zestiva Consultant / Practitioner ecosystem.

## Core Product Loop

**Collect → Understand → Track → Intervene → Measure → Improve**

## Status Vocabulary

Every capability should use one of:

- `CURRENT` — evidenced in the current product/runtime.
- `PARTIAL` — some implementation exists but the capability is incomplete.
- `TARGET` — approved product direction but not yet fully implemented.
- `FUTURE` — intended direction requiring later definition/approval.
- `EXTERNAL` — capability authority belongs outside Fiteatsy.

Documentation must not present TARGET or FUTURE capabilities as CURRENT implementation.
